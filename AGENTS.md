# cybersec-homepage

## Stack

- **Runtime**: Bun (package manager + dev server runner)
- **Frontend**: Vite + React 19 + TanStack Router (`frontend/`)
- **Backend**: Hono + Bun (`backend/`)
- **Database**: Supabase (Postgres) — `supabase/`
- **UI**: shadcn/ui + Tailwind CSS v4 (`frontend/components.json`)

## Commands

| Command             | What                                       |
| ------------------- | ------------------------------------------ |
| `bun run dev`       | Start frontend dev server (port 5173)      |
| `bun run dev:backend` | Start backend dev server (port 3001)     |
| `bun run build`     | Build frontend for production              |
| `bun run typecheck` | Typecheck both frontend and backend        |
| `bun run format`    | Prettier write (frontend)                  |

## Conventions

- **Frontend path alias**: `@/*` → `frontend/src/*`
- **Route tree**: `frontend/src/routeTree.gen.ts` — auto-generated by TanStack Router; regenerate after adding/renaming route files
- **Generated files** (`*.gen.ts`) — committed as-is
- **shadcn/ui**: add components with `bunx shadcn@latest add <name>` (run inside `frontend/`)
- **API proxy**: Frontend dev server proxies `/api` to `http://localhost:3001` (configured in `frontend/vite.config.ts`)
- **Style**: `verbatimModuleSyntax` — use `import type` for type-only imports
